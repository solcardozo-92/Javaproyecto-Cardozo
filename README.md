
Oráculo PRO - ProyectoFinal Cardozo

Instrucciones:
1. Descomprimir el ZIP.
2. Abrir index.html en un navegador moderno.
3. Si el navegador bloquea fetch en file://, ejecutar un servidor local:
   - `python -m http.server 8000` y abrir http://localhost:8000
4. El proyecto:
   - Carga mensajes desde mensajes.json usando fetch (datos remotos simulados).
   - Genera la interfaz (HTML) desde script.js.
   - Usa SweetAlert2 para pedir el nombre del usuario en vez de prompt/alert.
   - Muestra mensajes aleatorios y guarda un historial en localStorage.
   - Es escalable: podés editar mensajes.json para agregar más mensajes.

Nombre del archivo ZIP: ProyectoFinal+Cardozo_OraculoPRO.zip
